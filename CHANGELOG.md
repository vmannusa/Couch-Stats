# Couch Stats – Change log

## 2026-10-15
- Rewrote the README (features, stat sets, scripts, deploy notes) and added this change log.

## 0.1.0 – 2025-08-10
- First version: stat cards for basketball, football, baseball and soccer.
- Three themes: ESPN-like, ESPN Fantasy-like, Yahoo Fantasy-like.
- Randomize button, hand-editable stats, name, team and photo.
- Download the card as a PNG and copy a shareable link that rebuilds the card.
- GitHub Actions workflow to build and deploy to GitHub Pages.
- Dependencies added and updated (React 18, Vite 7, html2canvas, gh-pages); `package-lock.json` added.
- Several build-error fixes in `App.tsx` around the editable stats grid.
